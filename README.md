# Suits MVP

Next.js client scaffold for Suits. This repo is the web app only.

Auth and a database are intentionally out of scope. There is no NextAuth, Clerk, Supabase Auth, ORM, or other data layer in this project.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ESLint (Next.js defaults)

## Install

```bash
pnpm install
```

## Development

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000). The homepage is a placeholder titled **Suits MVP**.

## Build

```bash
pnpm build
```

Production start after a successful build:

```bash
pnpm start
```
